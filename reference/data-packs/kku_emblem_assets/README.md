# KKU Emblem and Brand Color Assets

รวบรวมจากหน้า “สัญลักษณ์ของมหาวิทยาลัยขอนแก่น” และแกลเลอรี Official LOGO ของ KKU สำหรับใช้ประกอบงานออกแบบ UI เว็บจองหอพัก

## Brand color

- ชื่อสี: สีดินแดง
- HEX: #A73B24
- RGB: 167, 59, 36
- CMYK: 24, 88, 99, 17
- ความหมาย: โยงกับลักษณะและภูมินามของพื้นที่มหาวิทยาลัย ซึ่งเป็นเนินดินลูกคลื่นสีแดง หรือ “มอดินแดง”

## Folder structure

- `images/official_png/` โลโก้ทางการ PNG ที่ดาวน์โหลดจากแกลเลอรี Official LOGO และรูปตราจากหน้า KKU
- `images/previews/` ภาพ preview รวมชุดโลโก้ เช่น Official, Sub-logo, Monogram และ swatch สี
- `images/anniversary_60/` โลโก้ 60 ปีที่ extract จากเอกสารประกาศ PDF ของ KKU
- `docs/` เอกสารประกาศ PDF ที่ใช้เป็นแหล่งของโลโก้ 60 ปี
- `data/` JSON/CSS/Tailwind snippet สำหรับนำสีไปใช้ใน UI
- `asset_manifest.csv/json` รายการไฟล์ ขนาดภาพ ขนาดไฟล์ hash และ source URL
- `source_links.md/json` แหล่งที่มาและลิงก์ดาวน์โหลดที่หน้า KKU ระบุไว้

## Notes

- ไม่รวมไฟล์ Font เนื่องจากคำขอนี้ต้องการเฉพาะสีประจำมหาวิทยาลัยและโลโก้
- ลิงก์ Google Drive สำหรับ PNG/AI ของบางชุดถูกบันทึกไว้ใน `source_links.md` เพื่ออ้างอิงต่อ
- ก่อนนำโลโก้ไปใช้จริงใน production ควรตรวจสอบข้อกำหนดการใช้งานตราสัญลักษณ์ของมหาวิทยาลัยอีกครั้ง
