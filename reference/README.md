# reference/ — ไฟล์ต้นทางและเอกสารอ้างอิง (ไม่ใช่โค้ดของแอป)

โฟลเดอร์นี้เก็บไฟล์ต้นทางทั้งหมดที่ใช้อ้างอิงในการพัฒนา แยกออกจากโค้ด (`src/`, `public/`) และเอกสารโครงงาน (`docs/`)

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `notion/` | Notion export ของ requirements ทั้งชุด (Hub + เอกสาร 01–17 + Feature Backlog / Open Questions / Payment Rule Matrix) — สรุปรวบยอดอยู่ที่ `docs/requirements-baseline.md` |
| `plans/` | แบบแปลนผังห้องต้นฉบับ: `แปลนผัง8 หลัง.rar` (ตึก 1–8 × 4 ชั้น), `ผังหออินเตอร์.rar` (ตึก A–D × 7 ชั้น) — เวอร์ชัน PNG ที่ใช้ในแอปอยู่ที่ `public/plans/` |
| `design/` | ไฟล์งานออกแบบ: Figma export, ต้นแบบ Vue เดิม (kku-dorm-light-dark-vue), ภาพ mockup light/dark |
| `media/` | ชุดภาพ/วิดีโอหอพักสำหรับใช้ในเว็บ (zip) — ภาพที่ใช้แล้วอยู่ที่ `src/assets/kku_dorm_images/` |
| `data-packs/` | ชุดข้อมูลประกอบ: ราคา/ค่าธรรมเนียม (kku_dorm_fee_assets), บุคลากร (dorm_kku_ui_assets), ตราสัญลักษณ์ มข. (kku_emblem_assets) |
| `agreements/` | เอกสารข้อตกลง/สัญญาต่าง ๆ จากหน้างาน (zip) |
