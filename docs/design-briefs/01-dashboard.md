# 01 — Dashboard (`/staff`)

> ต้องอ่าน `00-design-system.md` ก่อน · ออกแบบ 3 แนวทาง A/B/C ตามนิยามในไฟล์นั้น

## จอนี้คืออะไร

หน้าแรกที่เจ้าหน้าที่ทุกคนเห็นหลังล็อกอิน เป็น **fallback ของทุกบทบาท** — คนที่ยังไม่ได้รับสิทธิ์
ส่วนงานใดเลยก็ยังเข้าจอนี้ได้ (แต่ต้องเห็นหน้าแจ้งสถานะแทนตัวเลข)

หน้าที่หลักคือตอบคำถามเดียว: **"วันนี้ฉันต้องทำอะไรก่อน"**

## ข้อมูลที่มีจริง

### แถบทักทาย
- วันที่วันนี้แบบไทยเต็ม (`th-TH`, weekday + day + month + year)
- "สวัสดี, {ชื่อผู้ใช้}"
- คำอธิบาย pilot: "วรเรสซิเดนซ์ / หอ 8 หลัง + หอพักวรอินเตอร์ · ตัวเลขคำนวณจากข้อมูลห้องจริงรายห้อง"
- badge เขียวลิงก์ไปรอบรับสมัคร: "เปิดรับสมัครถึง {วันที่}" (แสดงเมื่อมี campaign เปิดอยู่)

### แถบสถานะห้องรวม
`RoomStatusMeter` + ตัวเลข "รวม N ห้อง"

### ตัวเลขปฏิบัติการ — 3 หมวด 11 ตัว

**ห้องพักและการจอง**
| ตัวเลข | ลิงก์ไป | tone |
|---|---|---|
| ห้องว่าง | `/staff/rooms` | success |
| รอรูมเมทยืนยัน (15 นาที) | `/staff/holds` | warn เมื่อ > 0 |
| รอชำระเงิน (72 ชม.) | `/staff/holds` | warn เมื่อ > 0 |
| ห้องยืนยันถาวรแล้ว | `/staff/rooms` | default |

**การเงิน SCB**
| ตัวเลข | ลิงก์ไป | tone |
|---|---|---|
| กลุ่มชำระยังไม่ครบ | `/staff/scb/results` | warn เมื่อ > 0 |
| รายการพร้อม export | `/staff/scb/export` | default |
| หน้า PDF ที่ match ไม่ได้ | `/staff/scb/pdf-import` | warn เมื่อ > 0 |
| Payment exception เปิดอยู่ | `/staff/scb/results` | warn เมื่อ > 0 |

**สัญญาและส่งต่อ**
| ตัวเลข | ลิงก์ไป |
|---|---|
| สัญญายังไม่ครบ | `/staff/contracts` |
| รอส่งมอบกุญแจ | `/staff/key-handover` |
| คิวส่งข้อมูลมหาวิทยาลัย | `/staff/handoff` |

### Panel "งานด่วนวันนี้" (ปัจจุบันอยู่คอลัมน์ขวา sticky 360px)
รายการงานที่ต้องมีคนตัดสินใจ **เรียงจากเร่งด่วนสุด** แสดงเฉพาะตัวที่ count > 0:

| งาน | tone | ลิงก์ |
|---|---|---|
| Payment exception รอจัดการ | danger | `/staff/scb/results` |
| หน้า PDF จับคู่ไม่ได้ | warn | `/staff/scb/pdf-import` |
| กลุ่มชำระยังไม่ครบ | warn | `/staff/scb/results` |
| สัญญารอดำเนินการ | normal | `/staff/contracts` |
| พร้อมส่งมอบกุญแจ | normal | `/staff/key-handover` |

ต่อท้ายด้วย **hold ที่กำลังนับถอยหลัง** แต่ละอัน: เลขห้อง + สถานะ hold + `HoldCountdown`
(label "เหลือเวลายืนยัน" สำหรับ 15 นาที / "เหลือเวลาชำระ" สำหรับ 72 ชม.)

ถ้าไม่มีอะไรเลย → ไอคอนเช็คเขียว + "ไม่มีงานค้างที่ต้องจัดการตอนนี้"

### Panel "กิจกรรมล่าสุด"
audit event 5 รายการล่าสุด: `detail` (2 บรรทัด) + `actor · เวลา` + ลิงก์ท้าย "ดู Audit log ทั้งหมด"

## ปัญหาที่ต้องแก้

1. **11 ตัวเลขเรียงเท่ากันหมด** ไม่มีลำดับความสำคัญทางสายตา — เจ้าหน้าที่ต้องกวาดตาทั้งหมดถึงจะรู้ว่าอะไรด่วน
2. **ข้อมูลเดียวกันปรากฏสองที่** — "Payment exception เปิดอยู่" อยู่ทั้งใน StatCard และ panel งานด่วน
3. **panel ขวาเป็นที่รวมของทุกอย่าง** ทั้งงานด่วนและ hold countdown ปนกันในลิสต์เดียว
4. **ไม่บอกแนวโน้ม** ตัวเลขเป็น snapshot ล้วน ไม่รู้ว่าเพิ่มหรือลดจากเมื่อวาน
5. เจ้าหน้าที่ที่มีสิทธิ์แค่ส่วนงานเดียวก็ยังเห็นตัวเลขของส่วนงานอื่น (ควรซ่อนหรือทำให้จาง)

## โจทย์เฉพาะจอนี้

- **A (Console):** ยุบทุกอย่างให้อยู่ในหน้าจอเดียวโดยไม่เลื่อน — ตัวเลข 11 ตัวเป็นแถบเดียวกระชับ
  แล้วให้พื้นที่ที่เหลือทั้งหมดกับ "งานด่วน" ที่กดทำงานได้ทันที
- **B (Workflow):** จัด Dashboard เป็น **ไทม์ไลน์ของวัน** — เช้าทำอะไร บ่ายทำอะไร
  หรือจัดตามลำดับ pipeline: จอง → ชำระ → สัญญา → กุญแจ → ส่งมหาวิทยาลัย พร้อมบอกว่าคอขวดอยู่ขั้นไหน
- **C (Focus + Split):** ซ้ายเป็นคิวงานทั้งหมดของวัน ขวาเป็นรายละเอียดของงานที่เลือก
  พร้อมปุ่มจัดการโดยตรง — ทำ Dashboard ให้เป็นที่ **ทำงาน** ไม่ใช่แค่ที่ **ดู**

## เงื่อนไขเพิ่ม

- ต้องออกแบบสภาพ **"ยังไม่ได้รับสิทธิ์เข้าถึงส่วนงาน"** ด้วย — ปัจจุบันเป็นกล่องกลางจอ
  ไอคอนโล่ + "ยังไม่ได้รับสิทธิ์เข้าถึงส่วนงาน" + คำอธิบายให้ติดต่อผู้ดูแลระบบ (กองบริการหอพัก)
- `HoldCountdown` อัปเดตทุกวินาที — ออกแบบให้ไม่กระตุกและไม่ดึงสายตาเกินไปเมื่อมีหลายอัน
- ตัวเลขต้องกดได้ทุกตัว และต้องเห็นชัดว่ากดได้
