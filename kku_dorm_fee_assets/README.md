## ขอบเขตข้อมูล

1. หอพักนพรัตน์ (หอพัก 9 หลัง)

## ไฟล์ใน ZIP

- `metadata.json` — แหล่งข้อมูลและรายละเอียดชุดข้อมูล
- `dorm_groups.json` — ข้อมูลกลุ่มหอพัก เบอร์ติดต่อ และบริบทสำหรับ UI
- `fees_normalized.csv` — ตารางค่าธรรมเนียมแบบ normalize ใช้กับ Excel/Google Sheets ได้
- `fees_normalized.json` — ตารางเดียวกับ CSV ในรูปแบบ JSON
- `fees_ui_data.json` — JSON แบบ nested เหมาะกับ frontend
- `fees_ui_data.ts` — TypeScript constant สำหรับนำไปใช้ใน Vue/React
- `ui-copy-pricing.md` — ข้อความตัวอย่างสำหรับทำ card ราคาใน UI
- `preview-pricing.html` — ตัวอย่าง pricing cards แบบ static เปิดดูได้ใน browser
- `source_notes.md` — ลิงก์แหล่งข้อมูลและหมายเหตุการใช้ข้อมูล
